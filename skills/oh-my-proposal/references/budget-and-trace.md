# Budget and trace checks

Use decimal amounts, one currency (CNY yuan in the frozen profile), unique item IDs and explicit category totals. The declared total must equal line items; declared categories must cover exactly the categories present; each ratio rule is bounded by 0..100 percent and is evaluated against a nonzero declared total.

Budget checks are separate from prose quality. A budget statement in a section is not accepted as arithmetic evidence unless the structured budget passes. Any mismatch, invalid numeric type, negative amount, duplicate item or missing category is an error.
