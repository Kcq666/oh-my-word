# 申请字段与规则依据

字段来源分别说明：软件技术名称/版本可来自项目配置但登记口径须确认；权利人、开发完成日期、权属基础由用户提供；环境/功能来自真实源码和运行记录；不把仓库组织名称当著作权人，也不把最后提交日期当完成日期。

`application-info.txt` 逐项列出输入值，空项保留未确认。当前没有内置全部官网字符限制；具体表单版本与字段要求在使用时核对，不照搬其他 Skill 的固定字数限制。

2026-10-16 核查的主要依据：[国家版权局《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)。第九条区分申请表、鉴别材料和证明文件；第十条规定源程序和文档前后连续页及不足规定页数时的全部交存；第十七条规定统一表格、中文和 A4。应结合登记系统当期说明核对适用性。

当前工具只保证已选原文的追溯和真实渲染页数，不认证已选部分等于整个源程序，也不自动证明连续交存、每页行数或权属。需要按官方页数规则裁取时先确认完整材料范围，再基于实际渲染结果处理；不以源码行数或字符数估算替代。

正式使用还需核对证明材料、软件名称/版本/权利人一致性、截图与手册来源、辅助写作人工核实及当期系统要求。preview 包不可升级为正式审阅包。
