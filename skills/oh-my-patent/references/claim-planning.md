# 权利要求规划与两类对照

发明/实用新型起草或修改权项时先做必要规划，可写进已有案件摘要。仅排版无需重做；外观设计不走技术权项规划。沿用 [通用模板](general-drafting-template.md)。

1. 从本案来源确定问题、实际贡献与必要技术关系，区分必要条件、实施例细节和可选改进。缺口具体提问，不用行业常见实现补造。
2. 拟定独权主题、必要特征和可支持概括，记录覆盖的实施方式与不能支持的边界。标准可帮助理解术语/测试条件，不自动成为独权必要限定。
3. 依据真实替代、参数或组合组织从属回退层次，核对引用关系；可比较不同范围的覆盖和支持，不以长度、数量或授权结果判优劣。
4. 本案支持与现有技术对照分别维护：

| 对照 | 内容 | 问题 |
| --- | --- | --- |
| 本案支持 | 特征 → 说明书位置 → 本案事实 → 概括理由/缺口 | 有无来源、实施与支持依据 |
| 现有技术 | 同一特征 → 文献原文/图件 → 公开日期/读取深度 → 相同/区别/未知 | 公开什么、区别是否成立 |

本案支持汇入 [支持记录](claim-support-contract.md)；对比文件不能替代本案实验与实现。文字覆盖不替代技术特征分解和范围判断；检索未完成保留限制，不保证授权。

申请后修改先取得原始申请、当前文本、审查意见和程序信息，对每个调整定位原始披露依据。新材料、同类专利或专家定稿不自动允许加入新事项。
