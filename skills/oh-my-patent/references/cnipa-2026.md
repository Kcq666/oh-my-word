# 中国国内专利申请规则与工具边界

核查日：2026-09-30。适用国内发明、实用新型和外观设计初次申请准备；PCT、复审无效、序列表及特殊领域另查专门要求。以下区分法律要求、写作建议和本工具策略。

| 项目 | 实际要求/边界 | 工具落实 |
|---|---|---|
| 电子格式 | 2026-01-01 起规定范围内文件采用符合国知局数据标准的 XML；不等于任意 XML | DOCX 审阅稿 + 官方转换交接；不输出自定义提交 XML |
| 法定文件 | 发明/实用新型请求书、说明书及摘要、权利要求等；外观设计请求书、图片/照片、简要说明 | 技术文书和图件；请求书在官方系统真实填写，本工具不冒充完整申请表 |
| 技术公开 | 专利法26(3)：清楚完整、使本领域技术人员能够实现；26(4)：权利要求以说明书为依据，清楚简要限定范围 | 事实溯源 + 逐特征支持 + 内容审查，不能只靠关键词 lint |
| 可专利性 | 新颖性、创造性、实用性；申请前公开、最接近现有技术和技术启示影响判断 | 专利检索及区别特征分析；不保证授权 |
| AI 方案 | 构建/训练通常公开必要模块、层级/连接关系、必需步骤参数；场景应用通常说明结合方式及输入输出内在关联 | 按实际发明必要程度披露，不能编造参数；不要求公开无关私有预训练细节 |
| 发明人 | 对实质性特点有创造性贡献的自然人；身份真实，不能填 AI/组织 | 入口确认，官方请求书填写；不在示例包含真实身份敏感信息 |
| 修改边界 | 申请后修改不得超出原说明书与权利要求等原始披露范围 | 新增事实仅解决起草前材料不足，不能许可申请后超范围补充 |
| 摘要 | 概述技术领域、问题、方案要点、用途；文字含标点不超过300字，不含商业宣传 | 字数检查；有说明书附图时指定最能反映技术特征的一幅摘要附图，拆分导出 |
| 权项 | 顺序编号、必要特征、引用在前；多项从属择一引用且不得作为另一多项从属基础 | 保留编号，不静默修复；支持及依附关系核对 |
| 两段式与章节 | 一般按实施细则规定撰写；发明性质不适用两段式或有特殊结构时允许适当方式 | 不把模板风格误认为无例外法定规则 |
| 实用新型 | 产品形状、构造或结合的技术方案；不能保护纯算法/方法 | 类型审查，必须有产品结构附图 |
| 外观设计 | 图片/照片清楚显示所保护外观；所需视图视实际设计而定，可有依法省略说明，不是所有案件必须六面图 | 简要说明与原图分别交接，按设计核对要点与视图；不从图片数量直接断言合法性 |
| 伦理 | 结合具体方案审查违法、社会公德、公共利益及数据相关规定 | 碰撞选择案例不是“年龄等一切输入都违法”；关键词只触发复核 |
| final 门禁 | 工具策略，非国知局认证 | 证据完备、审查闭合及形式错误消除后标 review_ready；转换和提交另验证 |

## 官方依据

1. [专利法（2020年修正）](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)：第2、22、26、27、31、33条等。
2. [实施细则（2023年修订）](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)：第11、14、19～26、30～31条等；2024-01-20起施行。
3. [局令84号，修改专利审查指南](https://www.cnipa.gov.cn/art/2025/11/14/art_99_202568.html)：2026-01-01生效，发明人、AI方案充分公开、技术与算法关联和创造性案例。该页提供2023指南（2025年修订）全文。
4. [全面实施XML通知](https://www.cnipa.gov.cn/art/2025/11/12/art_75_202551.html)：2026-01-01起规定范围、数据标准、工具下载与核对义务；ST.26序列表另依标准。
5. [XML推广及转换方式通知](https://www.cnipa.gov.cn/art/2025/5/26/art_75_199841.html)：官方工具、系统编辑及符合标准的第三方工具；证明文件等按适用规定处理。
6. [2026-07-01 XML问题解答更新](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectByNoticeId?weihuRid=325)：链接至当前FAQ及DOC。抓取到的是更新通知及下载入口，未把未读取附件内容当成已核实结论。
7. [官方专利审查指南PDF](https://www.cnipa.gov.cn/attach/0/%E4%B8%93%E5%88%A9%E5%AE%A1%E6%9F%A5%E6%8C%87%E5%8D%97.pdf)：摘要300字与一般格式；以官方当前全文及修改决定合并核对，不仅凭旧版本。

## 本轮未验证的部分

Linux环境没有实际运行官方Windows XML转换工具，也没有登入专利业务办理系统提交。未检验官方XSD/DTD与实际转换结果。因此新版提供可执行交接包与完整核对路径，不声称XML已生成或国知局系统已验收。转后必须核对公式、表格、附图、符号和权项，保留工具版本和回执。专业格式不能替代事实真实性与法律判断。

## 官方转换器进一步核实

已读取[官方工具入口](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=157)与该页“五书模板操作说明”PDF：官方明确提供Word/WPS申请文件转换、五书模板、复杂对象指导及两套用户手册。五书模板路径包含添加标记和按书生成XML。PDF的截图OCR部分有明显错字/重复，本工具只采用其清楚的操作正文，不把OCR样例中的专利技术内容视为本工具规范。入口/手册阅读不等于转换器运行成功。
