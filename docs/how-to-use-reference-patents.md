# 怎样使用已有专利

现在使用本项目，不需要先准备“数据集”、安装数据库或训练模型。直接提供本案真实技术材料，Skill 按材料选择领域，整理缺口，再起草和审查。

以后想利用已有专利时，几个词可以这样理解：

| 名称 | 实际指什么 | 什么时候做 |
| --- | --- | --- |
| 参考资料库 | 按领域整理、有出处的专利文件夹 | 手上已有一些值得参考的专利时 |
| 检索增强 | 起草时查找并读取相关参考文件 | 文件多到不能逐份阅读时，再接入查找工具 |
| 维护领域 Skill | 根据实际失败，修改该领域的提问和审查指导 | 发现反复漏问、漏写某类必要信息时 |
| 评测样本 | 另外留出的一组案件，用来比较改版前后结果 | 要判断改动是否有用时 |
| 模型训练 | 用专门服务和审定样本实际训练模型 | 本项目尚未提供，先不用推进 |

例如，有一份机械夹具交底和几份同类参考专利：

1. 交底用来确定本案真实结构、连接关系和实验；参考专利另列，注明公开号/出处与参考目的。
2. 起草时参考别人的术语和披露方式，也检查与已有技术的区别；别人的结构、参数和实验不能自动成为本案事实。
3. 如果几次真实案件都漏问某个关键连接关系，再把这个提问补到机械 Skill，并检查是否也适用于其他结构；不能因为一篇专利这么写，就要求所有机械申请照写。

阅读文件只为当前工作提供上下文，不代表模型永久学会了该领域。改 Skill 则能为之后加载该版本的任务提供新的指导，但效果仍要通过实际使用比较。

当前优先把解析、证据和输出检查修可靠；资料整理随真实需要逐步进行。
