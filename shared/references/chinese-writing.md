# 中文技术表达

根据 Fenng/Tech-Doc-Style-Chinese 的事实保真与术语原则改编；来源与 MIT 许可见仓库 THIRD_PARTY.md。

- 先保留事实、条件、例外和不确定性，再改善句子。不能将“计划”改为“已实现”，或将相关性改成因果。
- 同一概念使用一致术语；代码标识符、命令、URL、配置键和 API 字段保持字面值。
- 段落围绕一个主要信息展开，说明原因、机制或影响，避免空泛形容和无法核查的宣传语。
- 列表用于并列事项或操作步骤，表格用于可比较记录，不把所有正文压缩成标签。
- 模板、用户明确要求及具体领域规范优先于一般文风。企业技术报告不默认套机关公文格式。
- 缺少关键资料时说明缺口，保留可以完成的部分；不要为了流畅补造人名、日期、数字或验证结论。
